# browser-nutrition-extension
 A browser extension that provides real-time nutritional analysis for online food ordering platforms by extracting cart details and retrieving nutritional information using APIs.

## Setup Instructions
1. Clone the repository:

2. Navigate to the project folder:

3. **Set up API configuration:**
- Copy `config.example.js` as `config.js`
- Open `config.js` and **replace `YOUR_APP_ID` and `YOUR_API_KEY` with real values**.

4. **Load the Extension in Chrome:**
- Open `chrome://extensions/`
- Enable **Developer Mode**
- Click **"Load Unpacked"** and select this folder.
